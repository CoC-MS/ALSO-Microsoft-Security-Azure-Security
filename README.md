# ALSO Azure Security Best Practices

A one-page GitHub Pages guide covering eight pillars of Azure security: identity, compute, infrastructure and network, data and applications, posture and governance, logging and auditing, threat detection and response, and resilience.

The site lives in [`site/`](site) and is deployed by `.github/workflows/deploy-pages.yml` on every push to `main`. Enable it under **Settings > Pages > Source: GitHub Actions**.

Only English is available; the other languages in the dropdown are marked "coming soon".

Preview locally: `npx serve site`
